# SimonGame
DESCRIPTION:-
"Simon" is an extremely intuitive game that challenges the player’s cognitive retention by
making him or her memorize a pattern of buttons and then repeating it, with the pattern
growing by 1 each round.

FEATURES:-
1. Real-time updates on the game board to visualize the progress of the game.
2. Score tracking.
3. Three different difficulty options.
4. Option to start a new game at any point during the gameplay.

CONTROLS:-
Use any mouse button to click on a button in the game.
Correct pattern repetition advances the game to the next round.
Incorrect pattern repetition forces the player back to the main menu.
